# Dataset sources

`iris.csv` is the Iris dataset by R. A. Fisher (1936), downloaded from the [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/53/iris). UCI lists it under CC BY 4.0. The repository copy adds a header row and uses descriptive column names; observations are unchanged.

Citation: Fisher, R. (1936). *Iris* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C56C76.

`demo_sales.csv` is a small synthetic table created for testing missingness, dates, returns, and grouped sales calculations. It is not real sales data.
